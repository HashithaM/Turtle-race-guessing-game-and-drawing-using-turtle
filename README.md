# Turtle Race and Etch-a-Sketch

Two interactive Turtle graphics exercises: a randomized turtle race with a color-based bet, and a keyboard-controlled Etch-a-Sketch.

## Turtle race

- Choose one of six turtle colors
- Watch randomly paced turtles race to the finish
- Receive a win/loss result based on the selected color

Run the race with:

```bash
python main.py
```

## Etch-a-Sketch

`etch_a_sketch.py` maps the arrow keys to movement and turning, with `C` clearing and resetting the drawing.

```bash
python etch_a_sketch.py
```

The project uses only Python's standard `turtle` module and requires a graphical desktop environment.
